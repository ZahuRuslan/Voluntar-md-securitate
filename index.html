Instrumentul 1 — OWASP ZAP

Zed Attack Proxy · open-source

Proxy de interceptare și scanner de securitate pentru aplicații web. Explorează automat site-ul (Spider), analizează pasiv fiecare răspuns și poate rula atacuri active controlate.

  • • Detectează automat: antete lipsă, cookie-uri nesigure, resurse fără SRI, mixed content.
  • • AJAX Spider — util pentru paginile care se bazează pe JavaScript.
  • • Exportă rapoarte HTML / JSON / Markdown.

OWASP ZAP — familiarizare și utilizare

Pași practici, de la instalare la raport.

  1. 1Instalare

    Descarcă ZAP de pe zaproxy.org (necesită Java, inclus în installer-ul pentru Windows) sau folosește imaginea Docker.

    docker pull ghcr.io/zaproxy/zaproxy:stable

  2. 2Scanare pasivă (baseline) pe site-ul public

    Baseline-ul explorează limitat site-ul și analizează pasiv răspunsurile, fără atacuri active. Este potrivit pentru adresa publică.

    PowerShell (Windows)

    docker run --rm -v "${PWD}:/zap/wrk/:rw" -t ghcr.io/zaproxy/zaproxy:stable zap-baseline.py -t https://zahuruslan.github.io/voluntar-md/ -r zap-raport.html

    Bash (Linux / macOS)

    docker run --rm -v "$(pwd):/zap/wrk/:rw" -t ghcr.io/zaproxy/zaproxy:stable zap-baseline.py -t https://zahuruslan.github.io/voluntar-md/ -r zap-raport.html

  3. 3Scanare activă — numai pe copie locală

    Clonează repo-ul aplicației, pornește un server local și țintește localhost din ZAP (Automated Scan → Attack).

    git clone https://github.com/zahuruslan/voluntar-md.git
cd voluntar-md
python -m http.server 8080
# în ZAP: Automated Scan → URL: http://localhost:8080 → Attack

  4. 4Interpretarea alertelor

    Pentru site-uri statice, alertele frecvente sunt de configurare. Verifică în raportul tău dacă apar (numele exacte pot varia între versiuni):

    • Content Security Policy (CSP) Header Not Set
    • Missing Anti-clickjacking Header
    • X-Content-Type-Options Header Missing
    • Sub Resource Integrity Attribute Missing
    • Cross-Domain JavaScript Source File Inclusion
    • Strict-Transport-Security Header

    Fiecare alertă relevantă se trece în, cu captura și cererea/răspunsul ca dovadă. O alertă nu este automat o vulnerabilitate exploatabilă: confirmă impactul înainte de raportare.

  5. 5Raport

    Din GUI: Report → Generate Report (HTML). Atașează raportul generat la predarea lucrării.

Postman — scripturi de testare

Colecție de teste HTTP scriptate pentru Voluntar.md. Fiecare scenariu are scriptul gata de copiat.

Configurare

  1. Apasă Descarcă colecția Postman (sus) și importă fișierul în Postman (Import).
  2. Variabilele de colecție sunt deja setate: baseUrl și baseUrlHttp.
  3. Rulează tot folderul cu Collection Runner și urmărești PASS / FAIL în fila Test Results.

Rulare din linia de comandă (Newman)

npm install -g newman
newman run voluntar-md.postman_collection.json
